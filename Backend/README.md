# HireFlow – Backend

HireFlow backend is built using Node.js, Express, and MongoDB. It provides REST APIs for authentication, jobs, and applications.

## 🚀 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer (Resume Upload)

## 📦 Installation

```bash
cd backend
npm install

▶️ Run Server
npx nodemon server.js 


Server runs on:
http://localhost:5000

🔐 API Features

User authentication & role-based access

Job creation & management

Apply to jobs

Resume upload

Application tracking & status updates

📁 Folder Structure

controllers/ – Business logic

routes/ – API routes

models/ – Mongoose schemas

middleware/ – Auth & upload middleware
