# HireFlow – Frontend

HireFlow is a modern recruitment platform built with React and Redux that allows candidates to apply for jobs and recruiters to manage job postings and applications.

## 🚀 Tech Stack
- React
- Redux Toolkit
- React Router
- Axios
- CSS (No Tailwind)

## 📦 Installation

```bash
cd frontend
npm install

▶️ Run Application
npm run dev

The app will start on:
http://localhost:5173

🔐 Features

Authentication (Candidate / Recruiter)

Job listings & job details

Resume upload & apply flow

Recruiter dashboard

Application status management

Clean UI with animations

📁 Project Structure

components/ – Reusable UI components

pages/ – Application pages

features/ – Redux slices & logic

services/ – API layer
